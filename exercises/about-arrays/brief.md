# About Arrays

Predict how Ruby arrays are constructed, indexed, sliced, and changed.

Open `about_arrays.rb` and replace each `:fill_me_in` with the value produced by
its example. For indexing and slicing, the examples use
`[:peanut, :butter, :and, :jelly]`. Answers can be classes, integers, symbols,
arrays, or `nil`.

Explore positive and negative indexes, start-and-length slices, inclusive and
exclusive ranges, and the difference between an operation's return value and
the array it changes. Run the checks after each edit to see the next prediction
to investigate.
