# A useful custom collection

Packet wraps numbers. Implement each to yield all values and return an Enumerator without a block; include Enumerable. Order Packet objects by the sum of their values through Comparable and <=>. to_s should return "Packet(total)". `protocol` returns whether a Packet responds to each and is an Object. Do not change the caller’s array.

Use `rkoans check` to investigate one failing check at a time. Hints are optional.

Edit `core_protocols.rb` in this exercise's folder. Checks call
`Exercises::CoreProtocols` and its example classes.
