# Triangle Project

Implement `Exercises::AboutTriangleProject.triangle(a, b, c)` in `about_triangle_project.rb`.
Return `:equilateral` for three equal sides, `:isosceles` for exactly two equal
sides, and `:scalene` otherwise. This first project accepts valid triangles;
handling invalid lengths comes after the exceptions lesson.

Run `rkoans check` after editing. Each project is self-contained; it does not
read or overwrite another exercise's learner file.
