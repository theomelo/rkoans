# An endless queue

Implement `first_multiples(limit)` to return the first limit positive multiples of seven, starting at seven, using the endless range `(1..)`. Do not materialize the endless sequence. Zero returns [].

Use `rkoans check` to investigate one failing check at a time. Hints are optional.

Edit `lazy_enumeration.rb` in this exercise's folder. Checks call
`Exercises::LazyEnumeration` and its example classes.
