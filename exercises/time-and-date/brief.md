# Offsets and leap days

Implement `utc(text)` to parse an ISO8601 timestamp with an explicit offset and return the same instant formatted in UTC. Implement `days_between(first,last)` using Date ISO8601 parsing; return the integer number of calendar days, including leap days. Do not read the current clock.

Use `rkoans check` to investigate one failing check at a time. Hints are optional.

Edit `time_and_date.rb` in this exercise's folder. Checks call
`Exercises::TimeAndDate` and its example classes.
