# Three multipliers, one captured name

Implement `multipliers(numbers)` returning one lambda per number. Each lambda multiplies its single argument by its own captured number and rejects extra arguments. The starting for loop shares its loop variable, and Proc has different argument handling from lambda.

Use `rkoans check` to investigate one failing check at a time. Hints are optional.

Edit `closure_capture.rb` in this exercise's folder. Checks call
`Exercises::ClosureCapture` and its example classes.
