# Scoring Project

Implement `Exercises::AboutScoringProject.score(dice)` in `about_scoring_project.rb`.
Score a roll of zero to five dice: three ones earn 1000, other triples earn
100 times their face; leftover ones earn 100 and leftover fives earn 50.
Other dice earn zero. Each die counts once. Return zero for an empty roll.

Examples: `[1, 1, 1, 5, 1]` earns 1150; `[3, 4, 5, 3, 3]` earns 350.
