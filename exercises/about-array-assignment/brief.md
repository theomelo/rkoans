# About Array Assignment

Predict the values assigned by each example in `about_array_assignment.rb`.
Replace each `:fill_me_in` with a string, array, or `nil` as appropriate.

Explore assignment to one variable, parallel assignment, extra and missing
values, splats, nested arrays, a trailing comma, and swapping two variables.
Compare each variable's value after assignment with the original array.
