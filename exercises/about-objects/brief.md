# About Objects

Replace each `:fill_me_in` in `about_objects.rb` with the result of its example.
Answers include booleans, strings, integers, and the class of an object ID.

Explore ordinary values as objects, `to_s` versus `inspect`, identifiers for
distinct objects, and what happens when a plain object is cloned.

The small-integer ID examples observe MRI's representation on this course's
runtime. Their numeric pattern is an implementation detail; use identity
comparisons when reasoning about ordinary objects.
