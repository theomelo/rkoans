# A payload with a pin

Implement `amount(payload, kind)` to return a positive Integer amount only when a hash has type equal to the supplied kind and amount is an Integer greater than zero. Extra keys are allowed. Otherwise return nil. Practice a pinned variable and a guard in a pattern.

Use `rkoans check pattern-matching` to investigate one failing check at a time. Hints are optional.

Edit `pattern_matching.rb` in this exercise's folder. Checks call
`Exercises::PatternMatching` and its example classes.
