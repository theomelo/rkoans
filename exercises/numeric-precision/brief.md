# One third is not zero

Implement `ratios(a,b)` returning integer division, floating division, and exact Rational division under keys integer, floating, rational. Implement `imaginary_product(a,b)` for (a*i)*(b*i), returning Complex. Preserve exact Rational arithmetic when adding one.

Use `rkoans check` to investigate one failing check at a time. Hints are optional.

Edit `numeric_precision.rb` in this exercise's folder. Checks call
`Exercises::NumericPrecision` and its example classes.
