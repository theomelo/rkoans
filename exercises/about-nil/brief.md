# About Nil

Replace each `:fill_me_in` in `about_nil.rb` with the result described by its
example. Predict whether nil is an object, its supported conversions, and what
happens when a method it does not know is called.

For `missing_method_error`, supply the exception class. For `message_fragment`,
supply a nonempty string found in the exception's message. Predict a fragment
rather than the full message so diagnostic formatting can vary.
